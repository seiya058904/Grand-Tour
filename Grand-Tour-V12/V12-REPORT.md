## 2. 名牌：增加角色与实际状态，不增加满屏标签

浮动名牌仍然是两行：第一行姓名，必要时附短距离；第二行“角色 · 一条最重要状态”。例如 GC 主将、副将、冲刺手、爬坡手、爆发型、计时专家、全能车手。队内职务与基础类型分开：保护 GC 的副将不被错误显示成全都是 GC 主将；进入抢点或突围任务时可以显示其骑行类型。

状态从正在执行的比赛数据读取：积分点争抢优先于笼统的“进攻”；同时覆盖回应进攻、追击、补给、轮换、回归、掉队风险、恢复、疲劳、冲刺准备、火车、本组领骑、控速、护送、保 GC、观望等。没有为了“丰富”而随机伪造状态。

关注栏保留完整姓名、车队、职务与基础类型、实际前轮/选轮/同队关系、距离，再增加车队目标和真实耐力、爆发储备；有尚未过期的车手交流内容时才显示，不额外生成聊天或决策系统。

继续沿用 V11 的严格限额、2.6 秒停留、淡入淡出、扩大热区、加权命中、点击锁定和 Esc 取消。普通桌面精简上限 4 张、详细 5 张；390px 为 2 / 3 张，320px 为 2 / 2 张，淡出名牌计入上限。具体以比赛画布宽度而非显示器宽度为准。

同一种子和 120 个实际引擎 tick 的对比中，两版均为 **4 张名牌、0 对矩形相交**。V12 的收益是直接出现角色和更准确状态，不是继续减少到无法读比赛。名牌高度由 36px 增至 43px，以免强行缩小字体。该截图不是“所有场景永不相交”的统计证明。

## 3. 集团：持续分离、速度趋势、身份稳定与人数闭合

公路赛分组不再只依赖固定距离。沿纵向排序后，参考相邻局部车手速度、相对开口趋势、坡度、估计时间尺度和持续时间确认边界。正常公路赛约每 0.30 秒检查一次；明显的大断口可直接分开，较小且正在加速拉开的断口较快确认，普通暂时缝隙仍有迟滞。

定向场景中，两侧相距 10m、前组快 2m/s 的持续加速分离，在 1.2 个模拟秒内识别。这个数字是构造验证，不是任何真实比赛状态都必须在 1.2 秒分组的承诺。回并要求足够靠近、速度相近并持续接触，避免刚分开又立刻合并。

低速上坡专门补了一条边界回归：标准 4.4m 跟轮距离必须能被识别为已经接回。否则仅按速度缩小回并阈值，会让看似接上的小火车长期保留多个集团。此问题已修正并单独验证。

集团 UID 根据新旧成员重叠度匹配，最大延续片段优先保留身份；少数人从前方突围，不会抢走主集团原来的身份。命名区分前方突围、单飞、追击、主集团、后方小组和正在回归的集团；代表人物尽量稳定，实际最前位置另行展示。

每位仍在赛的车手只进入一个集团。过线、退赛等终止状态发生时，若组内人数与在赛人数不一致，同一个 tick 内刷新，避免等下一次例行检测才更新。

主看板仍只突出最多四组，但补充“其余 X 人 / Y 组”、单骑信息，以及“在赛 = 重点组人数 + 其余人数”。全场账目进一步列出已完赛、退出和未出发；侧栏也直接显示在赛人数 / 组数 / 全场人数，完整集团列表可滚动查看。

自然模拟取证为第 5 赛段、种子 314159、81.05 秒：**11 人突围 + 169 人主集团 + 2 人后方组 + 1 人单骑 + 1 人单骑 = 184 人，5 组**。未编辑任何车手坐标；浏览器重新执行同一输入至该时刻，逐一核对位置与原模拟一致，再冻结截图。

集团秒差采用 UI 层平滑估计，并在最前组身份改变时重新建立参考。正式同点计时、完赛时间和 GC 计分没有跟随显示平滑改变。与紧邻前组尾端的间隔和与全场最前端的秒差是不同量，不要求两处数值相同。

证据：`race-split.png`、`natural-scene-origins.json`、`visual-evidence.json`、`v12-focused.json`。

## 4. 车群动态：更清楚的串接与克制的错层

进攻响应者不再全部指向同一个发起者：按前后位置选择更近的前驱，先做短暂侧向切入，再衔接实际前轮。功率和制动仍由原有物理跟轮反馈决定，不赋予位置跳跃、免费速度或额外尾流。

小集团继续沿用已有领骑、轮换、末轮恢复。放宽不必要的组织冲突，使已分离的混合追击小组也能形成短列；对旧轮换缓存补充同组检查，防止分裂后还跟着另一组的缓存前轮。

大集团的极近似重合，在渲染层使用有限深度错层，并沿用平滑过渡；纵向比赛进度不移动。位置、物理车道、速度、能量、尾流来源与随机数状态不会被渲染器改变。定向检查覆盖 184 人和最大 1.08 深度单位偏移；这是画面深度单位，不是额外物理位移。

本轮曾尝试更强的实体防碰撞，多日赛发现它会不必要地拖慢车群、增加异常淘汰，因此没有交付该方案。最终保留更克制的可读性处理。密集车群仍允许自然的前后遮挡，没有声称“任何车轮和人体包围框绝不相交”。

## 5. 战术：更多有理由的追击与抢点

GC 威胁综合已有总成绩/时间尺度、前方位置与车手能力判断，避免把所有曝光突围都当作 GC 危机。追击组织从原先最多两队扩到通常最多三队，明确的较大 GC 威胁可协调四队；本队有人在前方、有无可用副将、体能和当前任务仍影响选择。定向威胁场景中，多支非 UAE 车队确实进入 GC 追击计划；无威胁的早期突围没有被同样处理。

受保护的 GC 主将在平路落到主集团后方且仍有储备时，优先使用现有功率与跟轮能力接回，不因本队冲刺手已过线而过早放松。没有瞬移追赶，没有修改结果表来“保前三”。

积分点前的接近窗口加长、参与意愿略提高；冲刺与 KOM 分别依据冲刺/爬坡能力、奖衫目标、体能、地形和当前任务筛选。保护主将和忙于追击/带冲的核心副将优先保留本职，闲置的合适副将可有条件参与，不再把整个 GC 车队一概排除。

冲刺点常规征召名额由原策略调整为 6，KOM 为 5；这不是禁止原有突围车手或其他既有任务参与争抢的全场人数硬上限。争抢发生后，仍由真实过点顺序发分；原有积分表、名次奖金与计分函数没有改变。

## 6. 两组完整多日赛对照

每版两个固定种子、每个种子完整运行 21 赛段，共 84 个赛段。采用相同的标准 GC 公开输入控制器：玩家始终是 0 号，每秒一次操作，适时补给、跟轮、计时赛配速和晚段 GC 响应。不是全体无玩家干预的 AI 实验，也没有把排行榜手工改成目标结果。

V12 两组中，波加查为第 1 / 1；温格高第 2 / 4；埃弗内普尔第 3 / 2；阿尤索第 5 / 3。强 GC 车手处于前列，但没有固定前三顺序。0 号由控制器驾驶，因此不能把他的胜利当作独立的全 AI 能力验证。

完整分赛段指标、前十、角色胜场、退出人数和控制策略在四份 `tour-v*-*.json` 中。模拟完成后仅调整了集团侧栏的 UI 文案/人数标记，比赛核心没有再变。

## 7. 领奖与主画面精修

普通赛段继续冠军单独亮相，最终 GC 才采用 2–1–3。未增加奖项或改变领奖计划。

动作增加站稳、接物、展示、挥手的节奏分层；入场时不立即做夸张举手。交接时加入轻微转头与点头，举花与挥手幅度更克制；工作人员伸手受手臂长度约束，避免无限伸长。主持人的持话筒姿势重新调整，最终 GC 宽景也保留主持人。部分观众加入错开节奏的轻微鼓掌，仍保留手机、相机和闪光。

保留并延续 V11 的连续镜头、同一获奖者复用骨架、不同人物先退后进，结算数据全程只读。不把工作人员展示奖衫描述成完整现场穿衣动画。

主画面增加克制的路肩植被层，继续统一深绿/黄的 UI、数字对齐和信息层级，低画质不增加这一层。整体仍为原项目的平面化轻量美术，不声称达到写实影视级人物模型。

约 31.8 秒录像来自真实 Chromium：先用原引擎推进至终点附近，再在正常 RAF 下录制冲线、单人及各奖衫环节、结算。无音轨。输出 30fps 通过真实时间戳保留上一实际帧，不使用 AI 补帧；30fps 是编码规格，不是稳定游戏帧率承诺。
