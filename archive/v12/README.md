# 环法 · Grand Tour — V12 精修候选版

直接打开 `grand-tour-v12.html`。浏览器页签图标与页头标志已嵌入 HTML，单独分发该文件也能正常显示。仓库中的同名 PNG 仅供 GitHub Pages 根入口设置 favicon，游戏 HTML 不依赖它。这是延续 V11 的轻量 2D 公路自行车比赛小游戏，可体验单赛段和 21 赛段多日赛。游戏本体不需要安装依赖、联网、编译或启动服务器。

本轮改进名牌角色与状态、集团识别与人数统计、多车队追击、积分点争抢、车群视觉错层和领奖动作。普通赛段仍是冠军单独领奖；最终 GC 为前三名共同登台。

使用旧进度前，先在 V11 导出备份，再在 V12 导入。保留原版及备份。存档格式仍为 V9，存储键未改；不同本地文件路径或浏览器可能隔离本地存储。公路赛战术已调整，导入后继续比赛不保证与 V11 产生相同赛果。

`V12-REPORT.md` 说明改动、验证与边界；`evidence/` 是实际截图和测试结果；MP4 是约 32 秒真实浏览器录像。`tests/` 为可选复核脚本，不参与游戏运行。

这是供真人试玩的候选版，没有把自动化通过等同于视觉“8 分”验收；最终视觉与手感仍需真人验收。
