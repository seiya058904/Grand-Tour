## 已执行验证

使用 Playwright Chromium（云端测试环境）加载交付 HTML 原字节，并以测试专用内存 Storage 运行。Browser 插件不可用；本环境的原生文件导航受策略限制，因此该流程不验证 `file://` 或浏览器重启后的磁盘持久性。

- 静态包检查、内嵌 JavaScript 语法、版本标记、唯一 DOM ID、无远程运行时资源、存档格式及 V20 冻结赛段数据。
- 21 个赛段逐站 100 tick 启动检查；504 个路线几何边界组合；6,144 组骨骼长度检查，最大误差约 1.42×10⁻¹⁴。
- 同种子重复、保存快照恢复并续跑 900 tick；渲染 40 帧不改物理状态；导入 V20 快照并续跑；内存存储往返恢复并续跑。
- 完整固定步长跑完平路、TTT、ITT、山地各一场：184/184 车手结算，未触发不变量失败。
- “恢复耐力／阈值”真实点击往返；选中背景和边框均为 `rgb(223, 211, 161)`，未选中背景为 `rgb(25, 45, 34)`，`aria-pressed` 与 V20 一致。自动跟轮和进攻时两档均不误显示为选中。
- 双层电台桌面、窄屏、暂停、淡出与 Reduced Motion；320/390/768 像素布局；车手标签避让；页面横向溢出为 0；本轮浏览器错误为 0。
- 赛段结算、结果页、下一站状态延续、雨景、定点跟轮、进攻与连续姿态。

赛段、战术、按钮、车群和截图证据位于 `evidence/rebuild-20260928/`；双层电台桌面／窄屏证据位于 `evidence/radio-rebuild-20260928/`。较早 V21 工作稿的证据仍保存在旧目录，仅供历史追溯，不作为本次重建版本的验收依据；本报告及 `SHA256SUMS.txt` 是本交付的索引。
