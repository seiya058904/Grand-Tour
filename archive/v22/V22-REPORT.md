# Grand Tour V22 · 本地交付与验证

交付日期：2026-09-29。基线为当前仓库 `cf7f21a` 的可运行 V21，先运行与观察原版，再修改独立的 `Grand-Tour-V22.html`。V22 标记为 `data-build=2200 / buildVersion=220`，仍为离线单 HTML，无新增运行依赖。

## 实际升级

- 延续 V21 深绿、纸黄与矢量骑行画风。HUD 使用更明确的仪表分区、稳定数字宽度；Race Centre 的导航、表格、人名与次级信息统一字号和间距。
- 姓名牌收紧至 40px 高，普通车手改用深底浅字，玩家保留黄色，指定前轮保持独立选中反馈。标签容量、停留保护、真实坐标、队服、遮挡与原有镜头不变。
- 桌面按窗口高度调整赛场与控制区：1280×720 的恢复、阈值、进攻、Auto、补给全部在首屏内。窄屏标题、命令行、三列仪表重新排布，消除原版 HUD 标签相撞；W/kg 独立成行，输出按钮说明缩短而保留数值含义。
- 修复赛前骑手画布裁掉头部与轮胎的问题，使用画布实际宽高约束比例。
- 修复进攻按钮的旧 ID / `!important` 样式冲突。原版进攻悬停时文字/背景对比度约 1.10:1；V22 实测为 10.82:1，普通及非悬停进攻状态也超过 4.5:1。保留恢复/阈值的选中语义与纸黄色。
- 对话框进入 160/260ms、退出 130ms；Race Centre 人工切页 180ms；控制反馈 150ms；结果领奖位有总计不足 0.6 秒的分层到达。动画可取消，快速重开不会被旧回调隐藏；关闭时立即释放游戏操作与恢复焦点，比赛不等待动画。Reduced Motion 使用无空间位移的即时对话框切换。实时遥测不反复触发面板入场。
- `index.html` 与 README 均将 V22 标为当前版本，首页入口指向 `Grand-Tour-V22.html`。
