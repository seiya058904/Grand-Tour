# V25 Canvas 缓存资源复查

正式候选 SHA-256：`1f5a338355180489b53e2c8fbe3cb8537103ebbf20bf79a1bc45054a3dfee4ec`。本记录区分原隔离实验、便携回归和最终正式性能采样；不会覆盖历史实验的来源哈希。

## 已确认的问题与局部修复

身体姿态缓存容量一直为 256，但颜色、相位、身份和姿态共同形成的 key 空间大于容量。原实现每次未命中都创建 108×132 Canvas，满容量时随后移除最旧 Canvas。在相同真实集团快照、全画质、1440×1000 DPR1、软件 SwiftShader Chromium 中，原 6 秒初探有 2,289 请求、1,724 未命中，约 75.3% miss，每秒新建约 285.5 个身体 Canvas。容量有上界，所以这项证据说明资源反复创建，不证明长期泄漏。

修复只改变满容量时获取重画目标的一个表达式：复用即将淘汰的最旧 Canvas；原 `width=108; height=132` 完整重置像素与 context 状态，原 painter、尺寸、姿态量化、key、绘画次数、LRU 容量和淘汰顺序保持。不存在 paint 回调重入缓存的路径。Canvas 新旧 key 重用发生在同一次同步函数调用中，淘汰后不会留下两个有效 key 指向同一幅缓存内容。

## 像素与计数证据

`cache-pixels/pixel-parity.json` 是合入后从正式文件重新运行的 98 项检查，全部通过，页面错误 0。V24 文件只提供旧 `cachedCyclistBody`，其余临时对照页全部来自当前 V25；对照页哈希恰好等于之前实际构建的 `558fdf…`。这不是把完整 V24 与 V25 景物作像素等价比较。

平路集团与山地各 48 帧完整 race Canvas 的 RGBA 字节完全相同，模拟快照未受渲染影响、模拟时刻和实际绘制人数相同。固定轨迹请求、命中、未命中、淘汰、缓存重画、直接身体绘画和容量全部相同；新 Canvas 数分别从 410 降至 244、从 870 降至 229，较低但非零的计数包含冷缓存填充。

另外两项在一个 JavaScript 任务中绘制 320 个不同 key，超过 256 容量；全部绘制完成后才做第一次 readback，像素依然完全相同。这覆盖先前画入目标 Canvas 的内容不会被后续源 Canvas 改写污染。其中一项在复用前故意给缓存 context 设置 save/transform、clip、alpha、合成、虚线、阴影和 blur filter；宽高重置清除了污染。此项也保持逐像素相等。

## 原隔离 ABBA 实验，保留真实边界

原文件位于 `evidence/render/body-cache/counter-abba.json`，来源为真实 `558fdf… → 1f5a33…` 构建。两种场景各 A→B→B→A，共 8 段，每段 2 秒预热加 6 秒实际 RAF。它使用 Map/绘画/createElement 计数包装，因此是插桩诊断，不是正式未插桩 V24/V25 发布性能数字。

| 场景 | 原版两次 mean CPU ms | 复用两次 mean CPU ms | 原版新 Canvas/s | 复用新 Canvas/s |
| --- | --- | --- | --- | --- |
| 集团 | 11.825 / 11.724 | 10.608 / 10.609 | 296.37 / 308.13 | 0 / 0 |
| 山地 | 14.318 / 15.542 | 12.506 / 13.251 | 481.54 / 455.74 | 0 / 0 |

全画质、有限数值、LRU≤256、页面错误和模拟推进门槛都通过。多数 CPU 分位数较低，但集团 FPS 约 27，差异很小；不能据此宣称明显提帧。山地第二段候选出现 83.4 ms 最大帧间隔、66.2 ms CPU，原两段最大帧间隔为 66.7 ms。这一长尾没有确认根因，应如实保留，不能写成最坏帧普遍改善或绝不回退。

两版真实 RAF 导致帧数/请求总数略有不同；严格“同一绘制工作”证据来自固定自然轨迹的像素测试，而不是把 ABBA 近似工作量说成完全相等。

复用明确消除了满容量后新 Canvas 节点创建。未单独测得垃圾回收耗时改善，也未测量 GPU backing、纹理或浏览器内部像素缓冲分配；每次宽高重置仍可能影响这些内部资源，所以不能推断它们减少到零。缓存本身仍有最多 256 份身体图像，并未降低图像数量、分辨率、相位数、车手数或模拟计算。

最终未插桩 12 段 ABBA 与 180 秒连续运行由主审在所有功能回归结束后独占运行，结论以那个实际报告为准。本记录不会提前赋予它 PASS 或性能增益。
